## 1. 当前机制（v2严格版）

> ⚠ **2026-11-04 起配平已由 v3「价态裁决」接管（见 §6）**。本节描述的是 v2 历史实现，
> 保留用于对比；其中「max_pos / max_neg + 金属优先」已不再是线上逻辑。

### `get_compound_formula(cards)` 流程

```
1. 统计元素出现次数 → elem_counts
2. ❌ 必须恰好 2 种元素 → 否则返回 {}
3. 分类正/负价候选：
   - 每种元素计算 max_pos / max_neg
   - 金属优先作为正价(pos_elem)
   - 找非同符号的负价(neg_elem)
4. GCD 计算最简比：ratio_pos : ratio_neg
5. ✅ 严格检查：actual_pos == ratio_pos && actual_neg == ratio_neg
6. 生成化学式
```

| 约束 | 值 |
|------|-----|
| 元素种类 | **严格 2 种** |
| 比例检查 | **精确匹配** |
| 倍数放大 | **不允许** |
| 正价选择 | **金属优先** |

## 2. 旧版机制（v1宽松版）

### `get_compound_formula(cards)` 流程

```
1. 统计元素次数 → elem_counts
2. 无元素种类限制
3. 取第一个正价 + 第一个负价
4. GCD 计算最简比
5. ✅ 宽松检查：k = actual/ratio ≥ 1 整数即可
6. 生成化学式
```

| 约束 | 值 |
|------|-----|
| 元素种类 | **不限** |
| 比例检查 | **宽松（允许倍数放大）** |
| 倍数放大 | **允许** |
| 正价选择 | **先遇到先得** |

## 6. v3 价态裁决（2026-11-04）

v2 留下两个洞：

1. **引擎侧放行**：`play_cards()` 只在「配得出式子」时校验比例，配不出式子时直接放行，
   于是 `ClN` / `NCl` 这类假化合物能混进桌面；
2. **默认配平只取极值**（金属最高正价 / 非金属最低负价），需要「非金属作正价」的
   `NCl₃`（N +3）、`BCl₃`（B +3）、`ClF`（Cl +1）一个都配不出来。

v3 = 「两条路径 + 一个裁决点」：

| 路径 | 函数 | 作用 |
|---|---|---|
| 默认配平 | `_assign_valences(cards, cv)` | 金属取最高正价 / 非金属取最低负价 / H 与含氧酸中心原子提升为正价；产出 `formula` + `ratio_ok` |
| 价态搜索 | `_search_valences(cards)` | 默认配平 `ratio_ok == false` 时，2~3 种元素按**实际张数** DFS 找解；金属 / 准金属取全部正价并降序（v4，见 §7） |
| 对外出口 | `get_valence_pairs(cards)` | 先默认配平，失败再搜索；返回 `{symbol: valence}`，供 AI / 提示使用 |

成立条件（`_valence_assignment_ok`）：

1. 至少一个正价元素、一个负价元素；
2. `Σ(价 × 实际张数) = 0`；
3. 正价元素的电负性 ≤ 负价元素的电负性（正价者必须更"金属"）。

### 6.1 调用方分工（容易误解的一点）

| 调用方 | 取价方式 | 最终校验 |
|---|---|---|
| AI（`AIPlayer._pair_valences`） | `get_valence_pairs()` | `play_cards → _assign_valences(cards, cv)` |
| 提示（`HintAdvisor`） | `get_valence_pairs()` | 同上 |
| 人类面板（`_update_valence_buttons`） | 每张牌 `common_valence` 的**全部价**，玩家自选 | 同上（UI 只预检「一正一负 + GCD 张数 + 手牌够不够」） |

即：**引擎是唯一裁决点**，面板列出的是超集（含引擎会拒的组合，玩家选了会收到 `-1`）；
AI / 提示因为只拿 `get_valence_pairs()`，天然不会提假化合物 ——
v3 时代代价是它们也不主动建议「低价金属」（如 Fe 1 张 + Cl 2 张 的 Fe(+2)，只能玩家在面板手选）；
**v4 起金属价域开放，这类组合 AI / 提示也会自动给出（见 §7）**。

### 6.2 判定结果对照

| 组合 | 默认配平 | 价态搜索 | 结论 |
|---|---|---|---|
| NCl / BrN / IN | 失败（非金属都落负价） | 无解（N 价域只有 -3/+3/+5，1:1 无法电荷平衡） | ❌ |
| NCl₃ | 失败（N 取 -3） | N +3 / Cl -1（N 3.04 ≤ Cl 3.16） | ✅ |
| NI₃ | 失败 | N -3 / I +1（I 2.66 ≤ N 3.04） | ✅ |
| BCl₃ | 失败 | B +3 / Cl -1 | ✅ |
| ClF（卤族互化开启） | 失败 | Cl +1 / F -1 | ✅ |
| Fe + 2Cl | Fe 取 +3 → 3 ≠ 2 | 金属只取最高价 → 无解 | 仅面板手选 Fe(+2) |
| Fe + 2Cl（v4） | 同上 | Fe 价域 [3, 2] → Fe(+2) / Cl(-1) | ✅ 自动（见 §7） |

`play_cards()` 侧：化合物分支 `get_compound_formula(cards, cv)` 为空或 `ratio_ok == false`
一律 `-1`，旧「空式子就放行」的分支已删除。
